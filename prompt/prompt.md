> 我们现在要开发一个桌面工具， 主要是悬浮于桌面，点击可以展开圆形扇形菜单， 菜单上的功能以后逐渐添加。 现在技术想要用 rust 和 iced 来实现。 你给分析下有没有什么问题， iced 开发是否有问题。
> 首先我们做第一个功能，把悬浮球通用控件制作出来， 菜单就做6 个模拟菜单吧， 点击会弹出窗口展示不同的数字。
> 悬浮球点击时，会直接调用默认菜单的功能。 双击才会展开菜单。
> 你要记住， 你负责生成代码， 你不要运行， 不要测试， 需要测试时告诉我怎么测试就可以了。 
> 项目目录中我们已经用 cargo new 创建了空项目， 有一个 `Cargo.toml` 文件， 你可以在这个项目基础上开发。
> 下面开发第一个菜单的功能，点击菜单项1， 会打开笔记记录窗口， 在窗口上方是笔记的保存目录输入框，如果用户未设置保存目录， 保存时提醒用户设置， 如果用户设置了保存目录， 则保存到设置的目录。 并且在 json 格式的配置文件中记录用户设置的保存目录。下次运行时， 会从配置文件中读取保存目录。 目录下方是笔记内容的输入框， 用户可以在输入框中输入笔记内容， 点击保存按钮， 会将笔记内容保存到设置的目录中。保存时生成当前时间作为文件名，格式是 `yyyyMMdd_HHmmss`，文件后缀是 `.md` 。 配置文件中也记下悬浮窗口拖动到的位置， 下次运行时定位到记录的位置。弹出的窗口不要盖在悬浮图标上， 检测一下左右哪一边的空间大， 显示到左边或右边。
